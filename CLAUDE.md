# jibinjohnson.in

Personal website of a web developer and SEO specialist in Trivandrum (Thiruvananthapuram), Kerala.

## Stack
- Plain HTML, CSS, JavaScript. No frameworks, no build step.
- Hosting: Cloudflare Workers static assets, not Pages (`wrangler.jsonc`: Worker `jibinjohnson` on the jibinjohnsoninfo account, assets from the repo root, no Worker script, no build step, `preview_urls: false`). Every push to main deploys live via Cloudflare Workers Builds; never push unconfirmed or placeholder work. Don't run `wrangler deploy` manually unless asked. `.assetsignore` keeps internal files private (git files, `wrangler.jsonc`, `.wrangler`, `*.md` including this file, editor folders, `.DS_Store`); add any new non-website file in the root to it. `llms.txt`, `robots.txt`, `sitemap.xml`, `_redirects` and `_headers` stay public. Redirects in `_redirects` (301s), headers in `_headers` (immutable `/assets/*` caching, security headers), both in the root. `not_found_handling: 404-page` serves `404.html`; `html_handling: auto-trailing-slash` serves each `folder/index.html` at `/folder/`. The www → apex redirect is a Cloudflare dashboard rule (`_redirects` can't redirect by domain). Contact form: Web3Forms (`action` https://api.web3forms.com/submit, hidden `access_key`, `subject`, `from_name` and a hidden `botcheck` honeypot; `main.js` sends it with fetch, no reload).
- Google tag: Google Tag Manager container `GTM-P5QZBS27` (Google Analytics runs through it). The snippet (the async `gtm.js?id=GTM-P5QZBS27` script + the inline `dataLayer`/`gtag('js', new Date())` script, exactly as Google gives it, no `<noscript>` iframe) sits once per page immediately after `<meta charset="utf-8">`, which stays first in `<head>` (charset within the first 1024 bytes). It is async and must never block rendering or move the hero portrait preload/`fetchpriority`. Add the snippet to any new page. The privacy page's "Cookies and tracking" section says the site uses GTM and Google Analytics (anonymous usage data, cookies set by Google); keep it true if tracking changes.
- Styles: `assets/css/main.css`. Scripts: `assets/js/main.js`. Images: `assets/img/`.
- Each page is a folder with `index.html`. Pages use relative paths (`../assets/...`); `404.html` uses root-absolute paths (`/assets/...`).
