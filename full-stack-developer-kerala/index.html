Questions about full-stack development.

What kind of software do you build?

Web-based business software: booking systems, dashboards, client portals and internal tools. I don't build native mobile apps.

How is a web application priced?

Web applications start from ₹30,000. I write a scope listing every screen and feature, and quote a fixed price against it.

Who owns the source code?

You do. The code lives in a GitHub repository under your account, and you get documentation for running and deploying it.

Can you work on an existing codebase?

Yes, if it's written in Python, Django or JavaScript. I start with a short paid review so the quote is based on the real state of the code.
